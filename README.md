## Course Scheduler Project
Advanced Web Development, Fall 2026, Aurora University   

This project is the first milestone of a Computer Science course tracking website for the classes offered at Aurora University. This was completed with my class partner, Ismael. As this was the first computer science project done with a partner or group, this was a good experience in learning how to tackle different parts of a project separate from one another.

Set up instructions are located in the course-scheduler README.md

Pieces of this project were aided using AI LLMs via ChatGPT to help write out chunks of the code. Using AI as a tool has allowed for projects of mine like these to be completed quickly while maintaining the same or similar level of understanding in
how the parts work together as a whole.
